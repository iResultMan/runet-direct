Переключать VPN больше не нужно

Обычно приходится выбирать. С включённым VPN не открываются банки и Госуслуги или просят лишнее подтверждение. С выключенным не работают зарубежные сайты. Остаётся переключать VPN туда и обратно и помнить, что сейчас включено.

С runet-direct VPN включён всегда. Служба сама разводит трафик: российские адреса идут напрямую, всё остальное через VPN.

Банки, Госуслуги, почта
Открываются сразу, как при обычном интернете. VPN выключать не нужно.
Зарубежные сайты
Идут через VPN всё время, а не только пока вы не отключили его ради банка.
Что делаете вы
Ничего. Не нужно ни переключать VPN, ни помнить, включён ли он.

Проверка — одна команда

Откройте терминал и введите runet-direct status. Если в последней строке написано Health: OK, российские адреса идут напрямую, а остальные там, где вы их оставили.

Служба запускается вместе с компьютером, сама скачивает список российских адресов (его публикует европейский регистратор RIPE NCC) и обновляет его раз в месяц. Если что-то сбросило маршруты, например раздача интернета с телефона или смена сети, она вернёт их сама.

Какой у вас VPN, неважно

Программа не пытается узнать, что за VPN стоит, и не зависит от его названия. Она проверяет результат: куда на самом деле уйдёт российский адрес.

Если VPN вставил своё правило раньше нашего и перехватил трафик, служба ставит своё правило выше и записывает это в журнал. Если исправить нельзя, она не молчит, а сообщает об утечке.

На macOS и Windows правил в таблице нет: побеждает самый точный маршрут. Установку и запуск там проверяет автоматическая сборка на настоящих системах.

Установка

Windows 10 и 11

Скачайте файл, запустите и нажмите «Установить». Понадобится пароль администратора.

Windows может написать «Неизвестный издатель»: у бесплатного проекта нет платной подписи. Нажмите «Подробнее», затем «Выполнить в любом случае».

runet-direct-setup.exe

macOS 11 и новее

Один файл для Intel и Apple Silicon. Откройте его, нажмите «Продолжить», затем «Установить» и введите пароль Mac.

Если macOS скажет, что не может проверить разработчика, откройте файл правой кнопкой мыши, выберите «Открыть» и подтвердите.

runet-direct.pkg

Linux

Ubuntu, Debian, Mint: дважды щёлкните скачанный .deb. Fedora и другие: .rpm. Нужен systemd. Версии для ARM лежат на странице релизов.

Или одной строкой для любого дистрибутива:

curl -fsSL https://raw.githubusercontent.com/iResultMan/runet-direct/main/install.sh | sudo sh
runet-direct.deb

Настраивать ничего не нужно. Через минуту после установки выполните runet-direct status. Все файлы лежат на странице релизов с контрольными суммами.

Управление

Всё, что делает служба, доступно командами. У них есть вывод --json и постоянные коды выхода, поэтому другие программы управляют службой так же, как вы.

runet-direct status
состояние службы и маршрутов
runet-direct check bank.ru
куда пойдёт этот адрес: напрямую или в VPN
runet-direct pause --for 1h
весь трафик через VPN на час, например чтобы увидеть сайт глазами иностранца
runet-direct exclude example.com --for 30m
этот сайт через VPN, потом вернётся сам
runet-direct add 203.0.113.0/24
эту сеть всегда напрямую; можно передать файл со списком
runet-direct config set ipv6.enabled false
IPv6 не трогать, IPv4 продолжит работать

Вопросы

Нужно ли что-то включать и выключать вместе с VPN?

Нет. Служба работает постоянно и не зависит от того, включён ли VPN в этот момент. Включили VPN один раз и забыли: российские сайты работают напрямую, остальные через него.

Безопасно ли это?

Программа не читает и не перехватывает трафик. Она только добавляет маршруты в таблицу системы и убирает их, когда вы её удаляете. Код открыт и лежит под лицензией MIT. У файлов релиза есть контрольные суммы и подтверждение происхождения сборки.

Куда программа ходит в сеть?

Раз в месяц скачивает файл со списком адресов с сервера RIPE NCC. Больше никуда. Телеметрии нет, учётной записи нет.

Что будет, если VPN отключится?

Российские адреса продолжат идти напрямую, остальные поведут себя так, как настроено у вас в системе. Службе VPN не нужен.

Как отправить один сайт через VPN?

Вставьте ссылку на сайт прямо из браузера: sudo runet-direct exclude https://сайт.ru/любая-страница. Диапазоны адресов знать не нужно, программа берёт адреса, на которые сейчас указывает имя сайта, и обновляет их каждые несколько часов. Чтобы вернуть как было: sudo runet-direct remove сайт.ru. Чтобы только на время: добавьте --for 1h.

Имя с www и без ведёт себя одинаково. Для сайта вместе с поддоменами: sudo runet-direct exclude '*.сайт.ru' (в кавычках; без кавычек можно писать .сайт.ru). Маска проверяет сам сайт и самые частые поддомены (api, m, static, cdn, lk, login и другие); остальные поддомены добавьте по имени.

Если у сайта очень много адресов (он стоит за сетью доставки), сработает не для всех сразу: проверяйте командой runet-direct check сайт.ru.

Один сайт всё равно открывается через VPN. Почему?

Список строится по российским адресам. Сайт, который стоит за зарубежной сетью доставки, в него не попадёт. Добавьте его вручную, можно вставить ссылку: sudo runet-direct add https://имя-сайта.ru. Проверить результат можно командой runet-direct check имя-сайта.ru.

Работает ли это с IPv6?

Да. IPv4 и IPv6 включаются раздельно. Если у вас нет IPv6, служба его просто пропускает.

Как удалить?

Windows: «Параметры», «Приложения», runet-direct. macOS: sudo runet-direct uninstall. Linux: sudo apt remove runet-direct или sudo dnf remove runet-direct. Маршруты снимаются при удалении.

Не блокирует ли это «аварийный выключатель» моего VPN?

Если выключатель устроен как правило файрвола, он блокирует и прямой трафик, и программа ничего с этим сделать не может. Отключите выключатель или добавьте исключение для вашего подключения.
